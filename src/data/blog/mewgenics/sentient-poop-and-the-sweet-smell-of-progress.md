Finally, some progression. And I get it. So much unlocked, so much more potential. I'm on the upswing again.

It has taken a while to get there. I have been banging my head against a skill ceiling / progression cap but the dam sure has burst now.

## Unlocks

In one fell swoop I unlocked several possible starting moves for four classes, a whole new class, a whole new biome, a new significant feeling quest and a whole new mechanic for my between run meta. If that sounds like a lot, it's because it is.

![Unlocking so much gave me another chance to see some interactions with the frankly very odd cast of characters in Mewgenics](src/assets/images/mewgenics/cat-grease.jpg)
_Unlocking so much gave me another chance to see some interactions with the frankly very odd cast of characters in Mewgenics_

I was thinking about which of the unlocks I was most interested in. Part of what makes this an exciting event in this title is that it's hard to say. They are all very cool and all make a material difference to how I play. Having done a run with the new class, I'm going to say that that's the thing I'm most interested in, as it introduces some neat changes.
